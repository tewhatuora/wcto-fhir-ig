### SDQ Parent Form

The SDQ Parent Form is a separate, licensed assessment completed by a parent, caregiver or whānau member.

| Attribute | Draft definition |
|---|---|
| Primary author | Parent / caregiver / whānau |
| Pattern | Single-author |
| Licensing | Licensed assessment |
| Candidate FHIR resources | `Questionnaire`, `QuestionnaireResponse`, `Patient`, `RelatedPerson`, `Observation` |
| Population | Contextual information only where authenticated and permitted |

> **In progress:** Questionnaire content, scoring representation, result mapping and licensing requirements remain to be confirmed.
