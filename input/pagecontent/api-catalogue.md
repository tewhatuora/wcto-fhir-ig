### WCTO Digital Services

| Service | Purpose | Detail |
|---|---|---|
| Magic Link API | Securely launch the required FHIR form and provide form-completion context | [Open](magic-link-api.html) |
| WCTO Schedule API | Manage due-list information, provider assignment, component status and overall completion | [Open](schedule-api.html) |
| WCTO Summary API | Provide authorised access to completed forms and generated summaries | [Open](summary-api.html) |

### Existing National Data Services

| Service | WCTO use |
|---|---|
| NHI API | Child identity, demographic and contact information |
| NES API | GP enrolment and provider information, including WCTO provider nomination where supported |
| AIR API | Immunisation history, status and updates |
| HPI API | Practitioner, role and healthcare organisation information |

See [National Data Services](national-services.html).

### Service Boundary

The WCTO guide describes how these services participate in the WCTO solution. It does not reproduce National API operations, profiles, security or conformance rules.
